# Student-Document-Request-Monitoring-System-PHINMA-Cagayan-de-Oro-College

Student Document Request Monitoring System PHINMA Cagayan de Oro College | Introduction to Computing Project
October 2026 | Bachelor of Science in Information Technology
 
 
 
Project Overview:
The Student Document Request Monitoring System is a simple Python console-based application designed to streamline the process of requesting and tracking academic documents at PHINMA Cagayan de Oro College. It replaces the manual, paper-based workflow with a centralized digital system, making document requests faster, clearer, and less stressful for both students and Registrar staff.
 
Problem Statement:
Manual processing causes delays of up to seven days for document requests, students cannot track request status in real time and must visit the office repeatedly, and the lack of a centralized system leads to misplaced records and heavier workloads for staff.
 
Key Features:
1. Students can submit document requests and check their status at any time
2. Registrar staff can view, search, and update all requests from one place
3. Every request receives a unique ID number for easy reference and record keeping
 
Objectives:
To provide students with a simple way to submit requests and monitor their progress, to help Registrar staff manage requests efficiently with fewer errors, and to keep digital records organized so documents are never lost.
 
Scope and Limitations:
The system serves current students and alumni requesting transcripts, enrollment certificates, and good moral character certificates. It is a console-based Python application and does not include website access, email or SMS notifications, or online file uploads.
 
System Requirements:
- Python 3.x
- Windows 11
- 4 GB RAM or higher
- 500 MB available storage
- Visual Studio Code
- Python Standard Library only
 
Getting Started:
1. Download the project files
2. Open the folder in your terminal
3. Run: python main.py
 
No additional installation is required beyond Python 3.x.
